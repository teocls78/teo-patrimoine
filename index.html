Mes actifs

Touchez un actif pour modifier son montant, changer son type ou le supprimer. Tout est enregistré automatiquement sur cet appareil — rien n'est envoyé sur internet.

Sauvegarde

Les données vivent dans la mémoire de ce navigateur, sur cet appareil. « Copie de secours » télécharge un fichier à ranger dans iCloud ou à s'envoyer par mail — indispensable avant de changer de téléphone. « Restaurer » le relit ensuite.

Ce fichier est en clair, même si un code protège l'application : c'est votre seul recours en cas de code oublié. Rangez-le dans un endroit sûr.

Sécurité

Le code chiffre réellement les données enregistrées sur cet appareil : sans lui, il ne reste qu'une suite de caractères illisibles, même pour quelqu'un qui fouillerait la mémoire du navigateur. Aucun moyen de le réinitialiser — gardez une copie de secours à jour.
